# Pomocnik Alfa — archiwum źródłowe

`pa-1.7.6-source-base.tar.xz` is a permanent archived **older** buildable
source baseline (without large binary audio assets), restored from the
owner's original Floot-hosted project. It is **not** the source of PA
1.7.66 and must never be called a full reconstruction.

Future PA source archives should be committed/versioned here or otherwise
stored durably. GitHub Actions artifacts with 3–7 day retention are not
an acceptable sole copy of essential project sources.

PA 1.7.66 source restoration is still blocked by expired
`Pomocnik-Alfa-1.7.36-CZYTNIK-ALFA-SOURCE` (run 37574069132).
