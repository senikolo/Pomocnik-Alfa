# PA6 2.4.5 — streaming and UI repair (test build)

The user reports that TV and Alfa Tube streams still fail after 2.4.4, and the UI intermittently hangs. No device log identifies the complete cause yet. This change addresses two concrete weaknesses in the previous integration and adds local diagnostics for the remaining device-specific failure.

- Java's existing validated HTTPS transport now retrieves remote video, audio, HLS playlists, segments and keys. LibVLC reads a session-specific HTTP server bound only to `127.0.0.1`. This avoids depending on the native TLS implementation for these media requests. Certificate and hostname verification remain enabled.
- HLS rewriting preserves redirect bases, signed query strings, byte ranges, separate audio groups and encrypted-key URLs. Local quality-selection masters have their remote references rewritten too. Remote status codes remain failures; nothing bypasses origin access restrictions.
- Session servers have bounded worker/route counts and close active decoder sockets on stop. New sessions get a new random URL prefix. No arbitrary local file is exposed.
- LibVLC's surface callbacks can synchronously invoke native `play` and `setVideoTrackEnabled` on Android's main thread. The embedded player's subclass dispatches these calls to its decoder queue, with generation checks. This is a plausible source of UI stalls; reproducing the user's precise stall still requires a device trace.
- Playback events maintain the displayed position instead of polling the native decoder. Hardware decoding may be used with software fallback; software decoding uses at most two codec threads.
- TV connection work is bounded to two workers and one pending request. Superseded requests are cancelled. Quality-master disk writes run off the UI thread.
- “Informacje o błędzie” copies the app/device version, safe connection failure details and the most recent main-thread stack recorded during a stall exceeding five seconds. The record stays on the device. No URLs, searches or viewed content are collected or sent.
